# Project Overview: Autonomous Terrain-Navigation Robot

This project involves an Autonomous Terrain-Navigating Robot designed to find and travel to a designated goal. The robot must navigate over obstacles, including a 3-foot wall, and locate a specific target, all while being timed for optimal performance.
